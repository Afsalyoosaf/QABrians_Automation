# QABrains E-commerce Website – Manual & Automation Testing

## Project Overview

This project involves Manual Testing and Automation Testing of the QABrains E-commerce web application. The objective is to validate key e-commerce functionalities, identify defects, and verify that the application behaves as expected.

Manual testing was performed to validate application functionality, while automated test scripts were developed using Java, Selenium WebDriver, TestNG, and Maven.

## Application Under Test

- **Application:** QABrains E-commerce Website
- **Test URL:** https://practice.qabrains.com/ecommerce/login
- **Application Type:** E-commerce Web Application
- **Testing Types:** Manual Testing and Automation Testing

## My Role

**Software Tester – Manual & Automation Testing**

- Performed manual and automation testing of key e-commerce functionalities.
- Designed and executed functional, positive, and negative test cases.
- Validated login, product listing, product search, wishlist, shopping cart, and checkout functionalities.
- Verified UI elements, page navigation, URLs, page titles, product information, and product sorting.
- Developed automation scripts using Java, Selenium WebDriver, TestNG, and Maven.
- Implemented the Page Object Model (POM) to improve code organization and maintainability.
- Used data-driven testing to validate multiple login scenarios with different credentials.
- Applied assertions and explicit waits to verify expected application behavior.
- Reviewed TestNG execution reports and analyzed failed test scenarios.
- Managed source code and project updates using Git and GitHub.
